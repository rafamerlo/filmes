## 🎥 Sobre o projeto

Bem-vindo(a) ao **FILMES**!

Este repositório é dedicado ao desenvolvimento de um projeto com temática cinematográfica.

A proposta é explorar o universo dos filmes por meio da programação, criando uma experiência visual moderna, organizada e intuitiva.

> 🍿 "A vida é como um filme, e cada momento faz parte da história."
